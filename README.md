# Spring Boot Products API

REST API developed with Spring Boot for product management.

## Technologies

- Java 17
- Spring Boot
- PostgreSQL
- Maven
- Spring Data JPA

## Features

- Create product
- List products
- Find product by ID
- Update product
- Delete product

## Endpoints

| Method | Endpoint |
|---------|---------|
| POST | `/products` |
| GET | `/products` |
| GET | `/products/{id}` |
| PUT | `/products/{id}` |
| DELETE | `/products/{id}` |
